# YogaRetreatBali

SEO-first yoga retreat marketplace built with Next.js App Router and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

## Key routes

- `/` marketplace homepage
- Programmatic SEO pages (e.g. `/yoga-retreat-bali`, `/7-day-yoga-retreat-bali`, `/luxury-yoga-retreat-bali`)
- `/about`
- `/retreats/location/[location]`
- `/retreats/filter/[filter]`
- `/api/retreats`
- `/sitemap.xml`
